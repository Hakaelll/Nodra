# English delivery, 6 November 2026

This delivery adds selectable English to web and Flutter while preserving Spanish and the approved design. It also ships the previously implemented verification-before-first-access flow in the Android APK. No translation service, paid provider, production dependency, emulator or GitHub workflow was added.

## Implementation and data boundaries

The reviewed shared catalog contains 837 messages. Both clients translate controlled interface copy, accessible names, validation, errors, status/role labels, dialogs, empty states and dates. Web metadata follows the selected language. Cookie and secure-storage preferences remain separate from session credentials. Switching language keeps form drafts and the current account/organization.

Names, service titles, chat messages, notice text and configured organization terminology remain user data. API notifications now expose their event kind through a bounded tenant-scoped lookup, allowing generated selection titles to be translated without translating user-authored titles. Existing mail templates, unknown API errors and historic stored bodies retain their original language. [Maintenance instructions](../LOCALIZATION.md) describe the scope.
